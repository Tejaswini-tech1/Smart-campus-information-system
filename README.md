# Smart Campus Information System

A web-based Smart Campus Information System designed to provide students with important campus information in one place.

## About the Project

Students often need to search through different sources to find information about their college, such as events, notices, departments, facilities, and other campus-related updates.

The Smart Campus Information System brings this information together in a simple and accessible platform, making it easier for students to find the information they need.

##  Objectives

- Provide campus information through a single platform
- Make important information easier for students to access
- Reduce the time spent searching for campus-related information
- Create a simple and user-friendly interface
- Demonstrate how technology can improve the student campus experience

##  Features

-  Campus announcements and information
-  Department-related information
-  Event and activity information
- Campus facilities information
-  Easy access to important campus details
-  Simple and user-friendly interface

## Technologies Used

- Python
- Streamlit
- Git & GitHub

## How It Works

1. The user opens the Smart Campus Information System.
2. The user selects the type of information they want.
3. The system displays the relevant campus information.
4. Students can easily navigate between different sections.
